# Support

Use this repository's issue forms for plugin installation, discovery, permission, process, envelope, and
tool-mapping problems. Report DocWen CLI, conversion, OCR, proofreading, or packaging problems that also
reproduce outside OpenClaw in the DocWen core repository.

Before posting, remove private file content, absolute paths, Gateway configuration, credentials, and personal
data. Use the repository Security page for vulnerabilities; never publish exploit details in an issue.
